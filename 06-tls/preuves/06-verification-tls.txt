# (seule adaptation pour nginx 1.24 : « listen 443 ssl http2 » au lieu de « http2 on », lignes IPv6 retirées)

  [OK] tls1_3 accepté — New, TLSv1.3, Cipher is TLS_AES_256_GCM_SHA384

  [OK] suite CBC refusée

Point 3 — En-tête HSTS avec includeSubDomains

    strict-transport-security: max-age=63072000; includeSubDomains
  [OK] HSTS présent, deux ans, sous-domaines inclus
  [OK] HSTS renvoyé aussi sur une réponse 404 (« always »)

Point 4 — Redirection HTTP → HTTPS

    HTTP/1.1 301 Moved Permanently
    Location: https://portail.labo-valmont.fr/resultats?id=42
  [OK] redirection permanente vers HTTPS, chemin et paramètres conservés
  $ curl -sI -H 'Host: site-pirate.example' http://portail.labo-valmont.fr/    attendu : redirection vers le VRAI nom
    Location: https://portail.labo-valmont.fr/
  [OK] en-tête Host forgé ignoré

Point 5 — Certificat et chaîne de confiance
  $ openssl s_client -connect portail.labo-valmont.fr:443 -servername portail.labo-valmont.fr -verify_hostname portail.labo-valmont.fr -verify_return_error -CAfile certs/ca.pem
    depth=1 C = FR, O = Laboratoire Valmont (TP), CN = Valmont Lab CA
    depth=0 CN = portail.labo-valmont.fr
    subject=CN = portail.labo-valmont.fr

  [OK] expire le Feb 11 15:53:35 2027 GMT (> 30 jours)
  $ curl -s -o /dev/null -w '%{http_code} %{ssl_verify_result}' --cacert certs/ca.pem https://portail.labo-valmont.fr/    attendu : 200 0
    200 0
